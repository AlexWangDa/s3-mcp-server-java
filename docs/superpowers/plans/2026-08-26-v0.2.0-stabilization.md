# S3 MCP Server v0.2.0 Stabilization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a reproducible, safe, tested v0.2.0 STDIO MCP server for AWS S3 and S3-compatible providers.

**Architecture:** Spring Boot binds and validates all settings in `S3Properties`, constructs managed AWS SDK v2 clients, and injects them into an MCP-facing `S3Service`. Dedicated local-path and S3-access policies run before every SDK call; repository-owned result records and stable tool exceptions isolate the MCP contract from AWS types.

**Tech Stack:** Java 17, Maven 3.9.11 Wrapper, Spring Boot 4.1.1, Spring AI 2.0.0, AWS SDK for Java 2.54.4, JUnit 5, Mockito, AssertJ, Testcontainers 2.0.5, MinIO `RELEASE.2025-09-07T16-13-09Z`.

**Spec:** `docs/superpowers/specs/2026-08-26-v0.2.0-stabilization-design.md`

## Global Constraints

- Preserve these tool names: `getBucketList`, `getBucketInfo`, `listObjects`, `getObjectMetadata`, `generatePresignedUrl`, `downloadObject`, `uploadObject`, and `createDirectory`.
- Java 17 is the minimum runtime; CI also verifies Java 21.
- Final dependency versions are Spring Boot 4.1.1, Spring AI 2.0.0, and AWS SDK BOM 2.54.4. Resolve release dependencies from Maven Central only.
- STDIO stdout contains MCP protocol messages only; application diagnostics go to stderr or `logging.file.name`.
- Remote mutation is disabled by default. Every local file path stays below `s3.local-root`, including after symlink resolution.
- Do not add delete, copy, move, batch, multipart, Streamable HTTP, native-image, container distribution, or S3 Transfer Manager support.
- Keep the version `0.2.0-SNAPSHOT` in the POM, MCP metadata, README examples, and packaged JAR name.

```java
@Validated
@ConfigurationProperties("s3")
public record S3Properties(
        URI endpoint,
        String region,
        String accessKey,
        String secretKey,
        String sessionToken,
        @DefaultValue("false") boolean pathStyleAccess,
        @DefaultValue("PT15M") Duration presignDuration,
        @DefaultValue(".") Path localRoot,
        @DefaultValue("true") boolean readOnly,
        List<String> allowedBuckets,
        List<String> allowedPrefixes,
        @DefaultValue("false") boolean allowLocalOverwrite) {

    public S3Properties {
        allowedBuckets = allowedBuckets == null ? List.of() : List.copyOf(allowedBuckets);
        allowedPrefixes = allowedPrefixes == null ? List.of() : List.copyOf(allowedPrefixes);
    }

    @AssertTrue(message = "s3.endpoint requires s3.region")
    boolean isEndpointRegionValid() {
        return endpoint == null || StringUtils.hasText(region);
    }

    @AssertTrue(message = "s3.access-key and s3.secret-key must be configured together")
    boolean isCredentialPairValid() {
        return StringUtils.hasText(accessKey) == StringUtils.hasText(secretKey);
    }

    @AssertTrue(message = "s3.session-token requires explicit access and secret keys")
    boolean isSessionTokenValid() {
        return !StringUtils.hasText(sessionToken) || isCredentialPairValid() && StringUtils.hasText(accessKey);
    }

    @AssertTrue(message = "s3.presign-duration must be between PT1M and P7D")
    boolean isPresignDurationValid() {
        return presignDuration != null
                && presignDuration.compareTo(Duration.ofMinutes(1)) >= 0
                && presignDuration.compareTo(Duration.ofDays(7)) <= 0;
    }
}
```

- [ ] **Step 4: Implement `LocalPathPolicy`**

Use one containment helper for both directions:

```java
@Component
public final class LocalPathPolicy {
    private final Path root;
    private final boolean allowOverwrite;

    public LocalPathPolicy(S3Properties properties) throws IOException {
        this.root = properties.localRoot().toAbsolutePath().normalize().toRealPath();
        this.allowOverwrite = properties.allowLocalOverwrite();
    }

    public Path resolveUpload(String input) {
        Path candidate = contained(input, true);
        if (!Files.isRegularFile(candidate)) {
            throw new S3ToolException(NOT_FOUND, "Upload source is not a regular file");
        }
        return candidate;
    }

    public Path resolveDownload(String input) {
        Path candidate = contained(input, false);
        if (Files.exists(candidate) && !allowOverwrite) {
            throw new S3ToolException(LOCAL_FILE_EXISTS, "Download destination already exists");
        }
        return candidate;
    }

    private Path contained(String input, boolean mustExist) {
        if (!StringUtils.hasText(input)) {
            throw new S3ToolException(PATH_OUTSIDE_ROOT, "Local path is empty");
        }
        try {
            Path supplied = Path.of(input);
            Path candidate = (supplied.isAbsolute() ? supplied : root.resolve(supplied))
                    .toAbsolutePath().normalize();
            if (!candidate.startsWith(root)) {
                throw new S3ToolException(PATH_OUTSIDE_ROOT, "Local path is outside s3.local-root");
            }
            Path checked;
            if (mustExist || Files.exists(candidate, LinkOption.NOFOLLOW_LINKS)) {
                checked = candidate.toRealPath();
            } else {
                Path parent = candidate.getParent();
                if (parent == null) {
                    throw new S3ToolException(PATH_OUTSIDE_ROOT, "Download path has no parent");
                }
                checked = parent.toRealPath().resolve(candidate.getFileName()).normalize();
            }
            if (!checked.startsWith(root)) {
                throw new S3ToolException(PATH_OUTSIDE_ROOT, "Symlink escapes s3.local-root");
            }
            return checked;
        } catch (InvalidPathException | IOException ex) {
            throw new S3ToolException(PATH_OUTSIDE_ROOT, "Local path cannot be resolved", ex);
        }
    }
}
```

`contained` resolves relative input against `root`, rejects normalized escape, resolves an existing upload with `toRealPath()`, resolves a download's existing parent with `toRealPath()`, and rejects any resolved path outside `root`.

- [ ] **Step 5: Implement `S3AccessPolicy`**

```java
@Component
public final class S3AccessPolicy {
    private final S3Properties properties;

    public S3AccessPolicy(S3Properties properties) {
        this.properties = properties;
    }

    public boolean allowsBucket(String bucket) {
        return properties.allowedBuckets().isEmpty()
                || properties.allowedBuckets().contains(bucket);
    }

    public void requireBucket(String bucket) {
        if (!StringUtils.hasText(bucket) || !allowsBucket(bucket)) {
            throw new S3ToolException(ACCESS_DENIED, "Bucket is not allowed: " + bucket);
        }
    }

    public void requireObject(String bucket, String key) {
        requireBucket(bucket);
        if (!StringUtils.hasText(key) || !properties.allowedPrefixes().isEmpty()
                && properties.allowedPrefixes().stream().noneMatch(key::startsWith)) {
            throw new S3ToolException(ACCESS_DENIED, "Object key is not allowed");
        }
    }

    public void requireMutation(String operation) {
        if (properties.readOnly()) {
            throw new S3ToolException(READ_ONLY, operation + " is disabled by s3.read-only=true");
        }
    }
}
```

```java
public List<S3Bucket> getBucketList() {
    ListBucketsResponse response = s3.listBuckets();
    String owner = response.owner() == null ? null : response.owner().displayName();
    return response.buckets().stream()
            .filter(bucket -> access.allowsBucket(bucket.name()))
            .map(bucket -> new S3Bucket(bucket.name(), owner, bucket.creationDate(), null))
            .toList();
}

public S3Bucket getBucketInfo(String bucket) {
    access.requireBucket(bucket);
    S3Bucket found = getBucketList().stream().filter(value -> value.name().equals(bucket))
            .findFirst().orElseThrow(() -> new S3ToolException(NOT_FOUND,
                    "Bucket does not exist: " + bucket));
    String location = s3.getBucketLocation(builder -> builder.bucket(bucket))
            .locationConstraintAsString();
    return new S3Bucket(found.name(), found.owner(), found.creationDate(), location);
}
```

- [ ] **Step 7: Translate AWS failures without leaking secrets**

Catch `NoSuchKeyException` as `NOT_FOUND`, HTTP 403 as `ACCESS_DENIED`, and other `S3Exception` values as `S3_ERROR`. Messages contain bucket/key only; causes remain attached for stderr diagnostics.

```java
private S3ToolException translate(S3Exception exception, String resource) {
    S3ErrorCode code = switch (exception.statusCode()) {
```
